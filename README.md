## qq-bridge v0.3.0 — 自动更新 + 桌面版一键安装 + 默认人格

### 朋友安装（3 步）

1. 安装并登录 **DeepSeek Harness 桌面版**
2. 解压本发行包，双击 **`安装.cmd`**
3. 双击桌面 **「启动QQ桥接」**

### 本版亮点

- **一键自动更新**：控制台顶部提示新版本 → 点击更新；自动备份 → 替换代码 → 恢复用户文件 → 数据迁移 → 重启 → 健康检查，失败自动回滚
- **桌面版 DSH 支持**：自动发现随机端口，安装脚本自动装进所有 DSH profile
- **默认人格保留**：内置「傲娇助手」「小鲸鱼」，装完即用
- **角色通用性**：不再内置私有角色/城市/世界数据，世界与生活系统默认关闭，新装不会自动写文件
- **数据迁移框架**：大型更新（如城市包）可保留朋友原有数据
- **全中文路径/文件名**：解压即用，无乱码

### 更新说明

- 0.3.0 起支持控制台一键更新；同版本线内的修订版本（如 `0.3.0-r2`）可自动升级
- 自动更新默认走 GitHub 发布仓库，国内网络失败时自动尝试镜像（ghproxy / gh-proxy）
- 更新前后会备份到 `_backups/update/`，可在控制台「回滚到上一版本」

## [0.3.0] — 2026-10-31

> **许可证变更**：0.3.0 起改用**专有授权许可**（免费个人使用，禁止再分发/商用/用于训练）；历史版本（≤ v0.2.1-r1）仍按 MIT。详见 [LICENSE](LICENSE)。

功能级更新：自动更新、桌面版一键安装、默认人格与角色通用性修复。

### 自动更新（0.3.0）

- **控制台一键更新**：顶部横幅提示「发现新版本」，弹窗可查看更新内容 / 版本 / 大小 / DSH 兼容范围，勾选「更新前自动备份」后点「立即更新」；也可「稍后」「跳过此版本」。
- **更新流程**：下载 → sha256+大小校验 → 完整备份（代码 + `config.json` + `state/` + `roles/` + `life-profiles/` + `osts/` + `audio/`）→ 只覆盖代码白名单 → **自动恢复用户文件** → 数据迁移 → 必要时 `pnpm install` → 重启 → 健康检查；失败自动整包回滚，控制台可手动回滚。
- **发布清单**：新增 `scripts/build-update-manifest.mjs` 生成 `latest.json`；发布时与 zip 一起上传 GitHub Release 附件。校验来源 https、sha256、大小，zip 路径穿越一律拒绝；Agent/MCP 无权调用更新接口。
- **数据迁移框架**：`src/data-migration.js` + `scripts/migrate-data.mjs`，按文件 `version` 逐级迁移、迁移前备份、未知字段保留；更新流程在恢复用户文件后自动执行，失败回滚。为城市革新等大型更新预留。

### 桌面版与安装（0.3.0）

- **桌面版 DSH 适配**：`启动.cmd` 自动发现桌面版随机端口并写回 `config.json`（`src/dsh-port.js` / `scripts/find-dsh-port.mjs`）。
- **一键安装**：`安装.cmd`（依赖 → 配置 → 全 profile 安装 preset/MCP → 桌面快捷方式）；自动发现 SnowLuma 连接（token/端口）并写回配置。
- **所有 profile 安装**：`setup-dsh.mjs` 默认安装到 `web` + `desktop` + 已存在的其它 profile。
- **默认人格**：发行包保留 `傲娇助手`、`小鲸鱼` 两张示例人格卡（可在控制台切换；不强制启用）。

### 修复（0.3.0）

- **角色通用性**：移除发行代码里写死的角色/城市默认值（原 `Jill` / `VA-11 HALL-A` / `Glitch City`）；新增 `config.characterId`（默认空），没有生活档案时世界/生活/情绪/关系/故事系统不启用，全新安装不再自动创建世界/故事数据。
- **不再自动写盘**：世界心跳、事件工坊、故事续写默认关闭，必须由用户显式开启；空角色时所有生成函数直接返回。
- 修复桌面版环境找不到 Node/pnpm 运行时导致首装失败；修复 zip 中文文件名编码（改用 bsdtar + UTF-8 标记）。
- 修复 SnowLuma 装在桌面目录时自动发现失败（新增常见位置浅扫）。

### 新增

- **每群聊策略**：每个群可单独设置参与方式（活跃 / 正常 / 安静 / 只回应 @ / 关闭）、主动频率、主动概率、普通消息回复概率、夜间是否必须点名、汇报方式和群规提示。
- **主人私聊跨群上下文**：只读取群聊，不读取其它私聊；仅在主人私聊注入，群聊里不会看到别的群内容。
- **跨群汇报**：每日摘要（默认 22:30）、急事立即汇报、每天最多 3 次、23:00–08:00 免打扰；汇报只给主人私聊。
- **跨群印象**：按「当前角色 + 群」保存 1～2 句第一人称碎片记忆，由当前角色自己的角色文件生成；后台按间隔写入，主人私聊只注入这些印象，不直接倾倒原始群聊记录。角色切换后不会串台。
- **安排（owner tasks）**：支持定时（每天 / 工作日 / 一次）、关键词、条件三种触发；到点只唤醒当前角色，不伪造用户消息；安排按角色隔离。
- **角色归属**：安排、跨群汇报、跨群印象都带 `characterId`；旧安排自动迁移到当前角色；控制台只显示当前角色的数据。群聊策略仍按群共享。
- **关系与情绪**：新增「关系与情绪」控制台页。情绪是短期状态；关系按「角色 × 人」保存熟悉度、信任、亲近、紧张四项长期印象，提示词只出现人话标签，不出现数值。关系按私聊/群聊 `scope` 隔离，AI 只能追加观察，删除/固定/改称呼由管理员操作；每天 04:30 左右尝试自动归纳（需要 DSH 在线），最多保留 100 人，固定的人不会被清理。**新增完整看法**：归纳时生成一段 120–800 字的第一人称长期印象，只在主人私聊注入；长度可在控制台按角色调整，也可以手动编辑。
- **修复关系记忆文件被覆盖**：`relationshipFile()` 统一小写角色文件名，避免启动时读 `Jill.json`、之后又把 `jill.json` 写成空状态；2026-10-28 已从最近会话重建活跃成员。
- **听话外音与承诺记忆（实验）**：群里生成回复前加入“先接眼前的话、只在有把握时顺着接”的提示；角色说出“等会儿给你/下次帮你”这类承诺后，按「角色 × 群 / 角色 × 主人私聊」记录，下次在同一会话开口时作为背景提示。控制台「关系与情绪」页可手动完成/作废，14 天自动过期。详见 `docs/guides/COMMITMENTS_AND_IMPLICIT_REQUESTS.md`。
- **到点跟进（人工确认 + 可授权自动，实验）**：承诺带“马上/等会儿/明天/后天”时计算到期时间；默认只在控制台生成「待确认」，**不会自动发消息**。管理员可以按场景显式授权“只观察”或“自动发送”；自动发送仍受免打扰（默认 23:00–08:00）、每场景每日上限、全局每日上限和现场条件约束。群友私聊永远不做跟进。
- **自动跟进授权（实验）**：控制台「关系与情绪」新增按场景的授权表，可选关闭 / 只观察 / 自动发送；默认关闭。自动发送只允许原群或主人私聊，默认 23:00–08:00 免打扰、每场景每天 1 次、全局每天 3 次；会检查“刚说过话”“会话太冷”“群策略关闭”等现场条件。后台每 60 秒扫描一次，自动发送仍由角色先看现场再决定是否开口。
- **承诺识别扩展**：承诺句识别范围增加“点一杯/下单/买/弄/调/安排/敬/去/回/再来”等动作，减少“点了酒却记不住”的漏记；到期换算增加“马上/这就/立刻 = 15 分钟后”。
- **对话级承诺识别（2026-10-30）**：现在会同时看“对方上一句”和“角色回复”，识别“对方请求 + 角色答应”的承诺。例如主人说“明天提醒我”，Jill 回“会的”，会记成“答应过主人：明天提醒我”；同一轮只记一条，角色后面补充的“明天买完，跟你报个数”不会重复建提醒。修复了此前只扫描角色单条消息、导致这类承诺完全不入账的问题。
- **GIF 抽帧故事板**：收到动图时抽取最多 4 帧拼成一张图，让模型看到先后变化，而不是只看第一帧。
- **角色专属 OST 记忆**：按角色读取 `osts/<角色>.json`，内容是“听到这首歌时想起什么”的第一人称记忆，不是曲目资料库；别的角色不会读到 Jill 的曲目。
- **按需聊天记录**：保留并打通合并转发/聊天记录卡片读取；需要时展开，不自动把大量历史塞进每次对话。
- **控制台页面**：新增「群聊策略」「安排」「跨群汇报」「关系与情绪」「聊天分寸」「抓睡觉」六页；跨群汇报页包含摘要、急事、免打扰、跨群印象和手动生成入口；关系页包含完整看法和承诺跟进；聊天分寸、抓睡觉均按角色隔离。
- **MCP 工具**：`qq_get_group_context` 允许管理员私聊按群查询最近上下文；只能从主人私聊调用。
- **自动备份与恢复**：每天自动备份 `config.json`、`state/`、`roles/`、`life-profiles/`、`osts/`、`audio/`；默认保留 7 份，备份目录在项目外，更新代码不会覆盖。控制台「调试与运维」可手动备份/改保留份数；命令行支持 `npm run backup`、`--list`、`--restore <目录> --confirm RESTORE`，恢复前会自动再备份当前数据。
- **聊天分寸**：识别连续冷场与明确拒绝；默认主人私聊 2 次、群聊被点到后 3 次短回复会暂时收住主动发言，直接被 @/点名/提问仍回应；2 小时自动恢复。阈值、恢复时间和“刚说过话”窗口可在控制台「聊天分寸」按角色调整；设置和会话状态都按角色隔离，只存计数和时间，不存消息内容。详见 `docs/guides/CONVERSATION_PACING.md`。
- **抓睡觉**：主人在私聊说过晚安后又在群里出现时，角色可以自然点一句“不是说晚安了吗”。控制台「抓睡觉」可调晚安有效期、再次出现窗口、同群冷却、语气（轻点/调侃）、自定义说法和允许生效的群；只对管理员生效，群友不会触发，也不会主动私聊群友。详见 `docs/guides/SLEEP_CATCHER.md`。
- **按人民币计价的省钱预算**：控制台「令牌与花费」新增预算区。日限额默认 ¥5，按实际 token 折算；可编辑高峰时段（默认工作日 09:00–12:00、14:00–18:00）。软阈值自动省电（思考强度 low、短回复、停主动/后台），警告阈值在最近会话自然说明一次，硬上限当天停止自动唤醒。预算按重置时间划日；首次启用当天从启用时刻开始算，避免把历史花费算进来。通知可切换「AI 按角色改写 / 固定文案」与「必须说 / 可以沉默」，固定文案支持 `{time}` 占位。后台每 30 秒刷新，状态变化会重新应用会话模型。详见 `docs/guides/TOKEN_BUDGET.md`。

### 安全与隐私

- 跨群数据只来自**群聊**；不读取、不汇总其它私聊。
- 跨群上下文、跨群汇报、跨群印象只注入**主人私聊**；群聊里不会看到其它群内容。
- `qq_get_group_context` 只接受主人私聊的 agent token；群聊内不可调用。
- 错误日志与汇报不输出 agent token、控制台 token、群成员隐私字段。
- 新增管理接口统一要求控制台 token；agent token 只能访问明确允许的工具/API。

### 升级说明

- 重启 `qq-bridge` 后生效；本次不需要手工迁移世界/记忆数据。
- 新增状态文件：`state/group-policies.json`、`state/owner-tasks.json`、`state/cross-group.json`；首次启动会自动创建。
- 新增关系状态文件：`state/relationships/<角色>.json`；首次启动会自动创建，旧的关系数据会自动迁移。
- 旧安排缺少 `characterId` 时，会自动归到启动时的当前角色；切换角色前建议先确认安排归属。
- 跨群汇报/印象依赖 DSH 会话与模型；模型不可用时本次跳过，不会伪造内容。
- SnowLuma 的 `statusCommand.swallow: true` 和 `versions/config.json` 的 `onErrorVersions` 属于网关侧配置，不随本仓库代码自动部署。
- 建议部署前备份 `state/`、`config.json` 和 `public/console.html`。

### 已知限制

- 每日汇报额度目前是全局的，不按角色拆分；急事可能占用当天摘要额度。
- 跨群印象是碎片记忆，不是完整档案；后台写手失败时本次跳过。
- 安排的条件触发目前只在群消息到达时检查；主人私聊中的条件触发尚未覆盖。
- 外部 embedding / 向量语义检索仍未实现；记忆检索使用 BM25 + 当前模型重排。
- 世界事件仍以模板池为主，LLM 生成随机事件尚未接入。
